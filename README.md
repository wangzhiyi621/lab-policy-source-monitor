# 公开政策目录检查

每周一北京时间约 10:37 检查国家医保局、卫生健康标准网和全国标准信息公共服务平台的公开目录。`feed.json` 保存目录标题、日期、官方链接及来源状态；`history.json` 保存最近 30 次检查。新增链接只属于**待核对线索**，不自动形成政策解读、执行要求或新旧条款差异。

本仓库只能上传本目录中的脚本、工作流和运行结果。不要加入医院文件、书籍、患者资料、192 份本地标准目录或原网站代码。浙江省和杭州市来源目前在网站作为人工核对入口，未纳入此定时程序。

第一次成功运行建立基线，不把目录中已有条目算作新增。某来源失败时保留历史线索，失败不表示没有更新；所有来源失败则记录失败并将当次 GitHub Actions 标记为失败。GitHub 计划任务可能延迟，长期不活跃的公开仓库可能暂停计划运行，需定期确认运行记录。

生化免疫网站的本地预览已只读接入 `feed.json` 与 `history.json`，正式网站尚未更新。网页显示每次来源状态和目录线索；来源读取失败时，既有相关线索保留并标明最近成功读取时间，不计为本次新增。首次按周定时触发尚待核验。原网站域名无需更换，目录结果不会自动发布政策解读或本院执行结论。
