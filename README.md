# 公开政策目录检查

每天北京时间约 10:37 检查国家医保局、卫生健康标准网和全国标准信息公共服务平台的公开目录。`feed.json` 保存目录标题、日期、官方链接及来源状态；`history.json` 保存最近 30 次检查。新增链接只属于**待核对线索**，不自动形成政策解读、执行要求或新旧条款差异。

本仓库只能上传本目录中的脚本、工作流和运行结果。不要加入医院文件、书籍、患者资料、192 份本地标准目录或原网站代码。浙江省和杭州市来源目前在网站作为人工核对入口，未纳入此定时程序。

第一次成功运行建立基线，不把目录中已有条目算作新增。某来源失败时保留历史线索，失败不表示没有更新；所有来源失败则记录失败并将当次 GitHub Actions 标记为失败。GitHub 计划任务可能延迟，长期不活跃的公开仓库可能暂停计划运行，需定期确认运行记录。

当前生化免疫网站仍是本地预览，未读取本仓库结果。先在 GitHub 连续核验定时运行、来源可读性和失败标记；确认可靠后，再将 `feed.json` 与 `history.json` 的公开只读地址接入网站的“待核实线索”区。原网站域名无需更换，也不自动发布政策解读或本院执行结论。
